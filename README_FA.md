# همسایه PWA — نسخه نمایشی اولیه

## اجرا در ویندوز
1. ZIP را استخراج کنید.
2. Python را نصب داشته باشید.
3. در پوشه پروژه نوار آدرس File Explorer را انتخاب کنید، `cmd` بنویسید و Enter بزنید.
4. اجرا کنید: `python -m http.server 8080`
5. در Chrome یا Edge باز کنید: `http://localhost:8080`

در مرورگر می‌توانید از منوی نصب برنامه، همسایه را نصب کنید.

## وضعیت
- رابط فارسی راست‌چین، داشبورد، واحدها، امور مالی، درخواست‌ها و اطلاعیه‌ها
- افزودن موارد در حافظه همان صفحه برای نمایش اولیه
- manifest و service worker پایه

## محدودیت
این نسخه فعلاً prototype است: ورود Magic Link و اتصال Supabase هنوز فعال نیست و داده‌ها به پایگاه داده ذخیره نمی‌شوند. برای اتصال واقعی باید فایل‌های `SupabaseEmailAuth`, `HamsayeCloud`, `CloudDashboardPage`, `CloudOperationsPage` و تنظیمات دیتابیس را بررسی کنیم. کلید `service_role` را هرگز در برنامه وب قرار ندهید.


## نصب روی iPhone (نسخه PWA)
1. این پوشه را روی یک میزبان وب با HTTPS منتشر کنید؛ برای نمونه GitHub Pages یا سرویس میزبانی مشابه.
2. در آیفون، نشانی HTTPS سایت را در Safari باز کنید.
3. دکمه Share را بزنید، گزینه Add to Home Screen را انتخاب کنید، گزینه Open as Web App را روشن نگه دارید و Add را بزنید.
4. آیکون «همسایه» روی صفحه اصلی ظاهر می‌شود.

نکته: این نسخه هنوز نمونه اولیه است و به Supabase یا سرویس پیامک متصل نیست. انتشار آنلاین لازم است تا روی آیفون قابل نصب باشد؛ آدرس localhost کامپیوتر ویندوز روی آیفون قابل استفاده نیست.
